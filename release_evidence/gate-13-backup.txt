Configuration Steps when Infrastructure is Available:

2. Drop/Recreate a test DB: createdb sensa_restore_test
3. Restore: pg_restore -U sensa_db_user -d sensa_restore_test -1 sensa_backup.dump
4. Verify record counts match exactly between original and restored DBs.
