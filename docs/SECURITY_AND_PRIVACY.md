# Security and privacy

Credentials are read server-side from environment variables. The repository’s `.env.example` contains placeholders. Private data, credentials, media, raw model results, caches and build output are excluded from publication. The release scanner checks proposed files and reachable Git history against configured keys, tokens, secrets, passwords and the private bootstrap password. It also checks frontend JavaScript, JSON, HTML and source maps for those values. Both frontend and backend Docker contexts exclude environment and private-key files. Regression tests inject artificial credentials to verify rejection without printing their values.

Users authenticate through salted scrypt passwords and random opaque sessions whose hashes are stored in the database. Cookies are HttpOnly and SameSite Strict. Production configuration requires HTTPS and secure cookies. Mutating browser requests validate Origin. Asset and case access is checked in the backend. Optional local mode permits same-origin loopback access and is rejected in production.

The read-only reviewer is a separate static service serving only the approved synthetic demo and reports. It rejects write methods and has no API route, database connection, worker access or model credential. The Compose HTTPS gateway routes only to this service. The live workers.dev dashboard serves static frontend assets and forwards `/api/*` through a Cloudflare VPC Service and Tunnel to the loopback-bound investigator API. In public mode, any visitor can view the owner's recordings and investigations, upload footage, modify investigations, and initiate billable model requests through a shared operator account. Administrator-only user and audit endpoints remain restricted. Evidence, database, worker processes and the model credential remain on the owner's computer.

Only use authorized footage. Original bytes and native artifacts are hash checked. External inference requires authorization, and uploaded provider files have explicit cleanup handling. Retention quarantine is reversible. Back up the SQLite database and evidence volume together, following [deployment](DEPLOYMENT.md).

Raw provider content, filenames, prompts and uploads are untrusted. Schema and frame-reference validation restrict accepted model outputs. FFmpeg calls use argument arrays and resource bounds. Decoder hardening, operator access, disk quotas and organizational privacy decisions remain deployment responsibilities. Review Meta terms for external processing of private footage.

Public source has no authorized project-wide open-source license. See [release notes](RELEASE.md) for provenance and dependency attribution.
